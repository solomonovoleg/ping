## На сервере (после деплоя)

Та же структура в папке проекта. Путь по умолчанию: **`/var/www/ping-moot`**.

```bash
ssh root@ТВОЙ_СЕРВЕР
cd /var/www/ping-moot
cat docs/DEPLOY.md    # полный деплой
cat deploy/README.md  # кратко + «потеря доступа к БД»
```

Файл **.env** на сервере при каждом деплое **перезаписывается** из твоего локального **deploy.env**. Поэтому **DATABASE_URL и остальное нужно хранить в deploy.env** — тогда доступ к БД не теряется.

## Если доступ к БД уже пропал

1. В **deploy.env** (локально) добавь или восстанови строку:
   ```bash
   DATABASE_URL=postgresql://ping_moot:ПАРОЛЬ_БД@localhost:5432/ping_moot
   ```
2. Выполни деплой: `npm run deploy` — скрипт запишет .env на сервер и перезапустит приложение.
3. Если пользователь/БД на сервере не созданы — зайди по SSH и выполни команды из **deploy/README.md** (раздел «Ошибка: Сервер не может подключиться к базе данных») или **deploy/create-db.sh** с заданным `DB_PASSWORD`.
