## Рекомендации по приоритетам

### P0 — Критично для работы

1. **Алгоритм ленты** — в старом `AdminDashboard` есть блок настройки алгоритма ленты (режим, буст, окна). В новой админке его нет. Стоит вынести в отдельный раздел «Настройки» или «Лента».
2. **Пагинация пользователей** — проверить, что список пользователей корректно пагинируется и не «ломается» при большом числе записей.

### P1 — Важно для модерации

3. **Чаты** — список чатов (ЛС и группы), участники, возможность удалить/архивировать чат. Сейчас нет.
4. **Поиск сообщений** — поиск по тексту сообщений по всем чатам (для модерации). API может быть, UI — нет.
5. **Аналитика** — графики регистраций по дням, активных пользователей за 7/30 дней. Сейчас только счётчики на карточках.
6. **Расширенный аудит** — фильтры по действию, по админу, по дате. Сейчас только список.

### P2 — Удобство и полировка

7. **Системные настройки** — флаги функций (feature flags), режим обслуживания, баннер для всех пользователей.
8. **Экспорт** — выгрузка списка пользователей (CSV/Excel) для отчётности.
9. **Уведомления** — рассылка push всем или выбранной группе (если есть инфраструктура).
10. **Модерация контента** — жалобы на посты/сообщения, очередь на проверку, массовое удаление.

## Технические улучшения

- **Единый API-клиент** — часть админки использует `lib/admin.ts`, часть — `admin/api.ts`. Имеет смысл свести к одному модулю.
- **Роли и права** — разграничение moderator / admin / super_admin на уровне UI (скрывать разделы, кнопки).
- **Responsive** — на узких экранах сайдбар сворачивается в горизонтальные табы; проверить, что все страницы удобны на планшете и телефоне.
