## 4.1. Автотесты

**Платформа (node:test или существующий раннер проекта):**

- Upsert счётчика: два сообщения в один чат — `sent_count` 2; разные `edge_id` — независимые строки.
- Milestone: `threshold = 10`, после 10-го сообщения один вызов мока «forward to EDGE» с `blockIndex = 1`.

**EDGE:**

- С правилом `chat_messages`, первый milestone → грант + XP.
- Повтор того же `ref_key` → без второго гранта.
- `maxPointsPerDay = 10`, `points = 10`: два milestone подряд в разных чатах в одни сутки — второй отклонён или урезан согласно ТЗ.

**Интеграция (по возможности):** минимальный e2e «сообщение → счётчик → stub EDGE» в dev-окружении.
