# Виртуализация списка сообщений в ChatDetail

## Зачем

В чатах с тысячами сообщений полный DOM всех пузырей даёт высокую стоимость layout и прокрутки.

## Ограничения

- **Динамическая высота** строк (текст разной длины, вложения, даты, системные плашки) требует `measureElement` или стабильных оценок; ошибка оценки даёт «прыжки» скролла.
- **Догрузка вверх** (`loadOlderMessages`) должна сохранять позицию — уже реализовано через `scrollRestoreAfterPrependRef` в `useChatMessages`; виртуализатор должен использовать тот же контейнер скролла.
- **Привязка к низу** (`scrollToBottom`, кнопка «Вниз») — нужна синхронизация с последним индексом в виртуальном списке.

## Технология

В репозитории добавлена зависимость `@tanstack/react-virtual`. Включение в UI — отдельный шаг после регрессии на длинных тредах. Экспериментальный флаг сборки: `VITE_CHAT_VIRTUAL_MESSAGES=1` (см. `.env.example`) — подключать только когда реализация в `ChatDetail` готова.

## До внедрения

Сохраняются: мемоизация строки (`ChatMessageRow`), ленивые изображения, prefetch хвоста из списка чатов, серверные оптимизации списка сообщений.
