# Улучшения диалогов/чатов: визуал и стабильность

Приоритизированный список изменений, чтобы чаты выглядели качественно и работали стабильно.

---

## 1. Стабильность и производительность

### 1.1 Виртуализация списка сообщений (ChatDetail)
**Проблема:** При 200+ сообщениях рендерится весь список — возможны лаги скролла и лишняя память.  
**Решение:** Окно видимости (windowing): рендерить только сообщения в viewport + небольшой буфер. Варианты: `@tanstack/react-virtual` или `react-window`.  
**Приоритет:** высокий для длинных переписок.

### 1.2 Восстановление скролла при подгрузке старых
**Сейчас:** Используется `scrollRestoreAfterPrependRef` и `requestAnimationFrame` — в целом ок.  
**Проверить:** Нет ли двойного кадра или мигания при `loadOlderMessages` на слабых устройствах. При необходимости — один `requestAnimationFrame` + `flushSync` только если появятся артефакты.

### 1.3 Мемоизация рендера сообщений
**Идея:** Обернуть один «пузырёк» сообщения в `memo`, чтобы при добавлении нового сообщения не перерисовывались все предыдущие. Уже есть мемоизация в списке чатов (`ChatRow`), в ChatDetail — каждый пузырёк пересчитывается при любом изменении.  
**Приоритет:** средний.

## 2. Визуал: экран чата (ChatDetail)

### 2.1 Убрать имя отправителя над каждым сообщением в личке (DM)
**Сейчас:** Над каждым сообщением показывается «Вы» / имя собеседника.  
**Лучше:** В чате 1-на-1 имя не показывать над пузырьком (оставить только в группах). Так интерфейс чище и привычнее (как в Telegram/WhatsApp).

### 2.2 Группировка подряд идущих сообщений от одного отправителя
**Сейчас:** У каждого сообщения свой аватар и отступ.  
**Лучше:** Несколько сообщений подряд от одного человека без длинной паузы — визуально «склеить»:
- один аватар на группу (или без аватара у «хвоста»);
- уменьшенный вертикальный отступ между пузырьками в группе (например `gap-0.5` внутри группы, `gap-3` между группами);
- скругление: у первого пузырька группы — верхнее скругление больше, у последнего — нижнее (или наоборот по дизайну).

Это сильно улучшает читаемость и «качество» ленты.

### 2.3 Разделители дат в ленте сообщений
**Сейчас:** Только подсказка внизу и время на каждом сообщении.  
**Лучше:** Вставлять линию с текстом «Сегодня», «Вчера», «15 марта» при смене дня (по `createdAt`). Так проще ориентироваться в длинных чатах.

### 2.4 Подсказка «Нажмите ⋮ на сообщении…»
**Сейчас:** Всегда видна над лентой при наличии сообщений.  
**Лучше:** Убрать в тултип к кнопке ⋮ в шапке или показывать один раз (localStorage), либо коротко в пустом состоянии чата. Тогда лента визуально чище.

### 2.5 Единообразие пузырьков и отступов
- Один и тот же `max-w-[82%]` уже есть — ок.
- Проверить: одинаковые `rounded-xl` / `rounded-br-sm` для своих и `rounded-bl-sm` для чужих.
- Тень: у чужих `shadow-sm` — при желании можно слегка усилить контраст фона (`bg-card`) на тёмной теме.

## 3. Визуал: список чатов (Chats)

### 3.1 Секции по датам
**Сейчас:** Есть `groupChatsByDateSection` и заголовки «Сегодня», «Вчера», «На этой неделе», «Ранее» — всё ок.  
**Проверить:** Стиль заголовков секций (`text-[11px] font-medium`, `sticky top-0`, `backdrop-blur`) — при быстром скролле нет ли лишнего мерцания. При необходимости задать `top` с учётом высоты шапки (например `top-[120px]` или CSS-переменная).

### 3.2 Скелетон загрузки
**Сейчас:** 7 строк-скелетонов при `isLoading` — нормально.  
**Опционально:** Подровнять высоту строк скелетона под реальную высоту `ChatRow` (например `min-h-[52px]` / `min-h-[var(--uix-touch-min)]`), чтобы при переключении на данные список не «прыгал».

### 3.3 Разделитель между строками чатов
**Опционально:** Тонкая линия между элементами (`border-b border-border/30`) или чуть более выраженный `gap` — на вкус; сейчас `gap-0.5` между чатами внутри секции. Можно оставить как есть.

## 4. Мелкие полировки

### 4.1 Плавность скролла к сообщению
**Сейчас:** При переходе по ссылке с `?messageId=` выполняется `scrollIntoView({ behavior: "smooth" })`.  
**Проверить:** На iOS/Android плавность может ограничиваться браузером; при проблемах — оставить `behavior: "auto"` для мобильных.

### 4.2 Индикатор «Загрузка…» при подгрузке старых
**Сейчас:** Текст «Загрузка…» сверху ленты.  
**Опционально:** Небольшый скелетон или спиннер вместо текста — визуально аккуратнее.

### 4.3 Длинные слова в тексте
**Сейчас:** `break-words` на пузырьке — ок.  
**Проверить:** Очень длинные URL без пробелов не должны раздувать пузырёк по ширине; при необходимости добавить `overflow-wrap: anywhere` или обрезку с многоточием для превью ссылок (если будет отдельный тип сообщения «ссылка»).
