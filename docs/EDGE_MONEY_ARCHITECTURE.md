# EDGE MONEY — архитектура ролей и потоков

Документ фиксирует **кто что делает** в модуле EDGE MONEY: создатель (админ/борд), платформа, микросервис EDGE и конечный пользователь. Без дублирования полной продуктовой спеки — только границы ответственности и текущее состояние реализации.

---

## 1. Участники системы

| Роль | Где в продукте | Суть |
|------|----------------|------|
| **Создатель (владелец страницы)** | Борд: `/board/edge`, мастер `/board/edge/new-money` | Настраивает игру, публикует кампанию, создаёт пост с `edgeId`. |
| **Платформа (основной сервер)** | `server/`, БД постов, сессии, прокси `/api/edge/*` | Посты, лента, авторизация, проксирование к EDGE с секретом, будущие хуки событий (чат, звонки и т.д.). |
| **Микросервис EDGE** | `EDGE/`, отдельная БД кампаний | Хранит кампанию `edge_type = money`, `config_json.money`, лидерборды/участников (общая модель с персонажем). |
| **Участник (пользователь приложения)** | Лента, `/edge/:edgeId`, UI `features/edge-money-template/` | Видит карточку в посте, открывает полный экран, смотрит рейтинг и правила; баллы появятся после внедрения событий платформы → EDGE. |

---

## 2. Что делает создатель (админ / борд)

1. **Выбор типа** на хабе EDGE: «EDGE MONEY» → мастер создания черновика с `edgeType: "money"`.
2. **Конфигурация** (шаги мастера, сохранение через `PATCH` создателя на платформе → EDGE):
   - **Карточка игры:** заголовок для игроков, опционально медиа (URL).
   - **Правила баллов:** какие виды активности включены, порог и баллы за шаг (`config_json.money.scoringRules`).
   - **Призы по местам:** диапазоны мест и подпись приза (`money.prizeTiers`).
   - **Рейтинги:** по умолчанию для MONEY при создании включён дополнительный рейтинг; основной обычно выкл.
   - **Сроки и видимость:** дата завершения, подсказки текстом, кто видит пост (`displayAudience`).
3. **Публикация** статуса кампании и **создание поста** с привязкой `edgeId` — иначе игра не попадёт в ленту (как у обычного EDGE).
4. **Итоги / розыгрыш** — через существующие инструменты борда «Подвести итоги» (при необходимости дальнейшая доработка под чисто денежные тиры).

**Код (ориентиры):** `client/src/features/edge-money-board/`, `client/src/pages/BoardEdgeMoneyNew.tsx`, `EDGE/creator/*`, `EDGE/money/creator/merge-money-patch.ts`.

## 3. Что делает пользователь (участник)

1. **В ленте / в посте** видит блок **EDGE MONEY** (квадрат 1:1): краткий заголовок, **фрагмент рейтинга** (топ и при наличии — «ваше место»), подсказка про полную версию, кнопка **«Вступить в игру»** (для гостя — призыв войти).
2. **По нажатию** переходит на **`/edge/:edgeId`** (как у Companion): полноэкранный интерфейс в стиле шаблона Prize Swipe:
   - **Инфо** — призы по местам, срок, как участвовать.
   - **Главная** — медиа/приз, прогресс (баллы относительно лидера), таймер до даты окончания, таблица рейтинга.
   - **Задания** — список **включённых** правил из конфига (пояснение, что выполнение — в приложении; кнопки «выполнить» в шаблоне заменены на информирование).
3. **Навигация:** свайп влево/вправо и нижние точки «Инфо · Главная · Задания».
4. **Старт отслеживания:** на вкладке «Задания» игрок обязан нажать **«Начать отслеживание заданий»** (`POST` → `edge_participants.money_tracking_started_at`). Пока метки нет — не начисляются баллы за приглашения, ЛС, звонки 1:1, посты, реакции и правило MONEY `follow_creator`; выдача пачки кодов приглашения тоже заблокирована.

**Данные для UI:** публичный конфиг `GET /api/edge/money/campaign-config`, лидерборд `GET /api/edge/participant/leaderboard` (для MONEY — преимущественно `kind=secondary`).

**Код (ориентиры):** `client/src/features/edge-money-template/`, `client/src/lib/edge-money-public.ts`, ветвление в `EdgeCompanionFeedHero` и `EdgeCompanion` при `edgeType === "money"`.

## 4. Поток данных (упрощённо)

```text
Создатель → Борд → PATCH /api/edge/creator/campaigns/:id (moneyConfig, schedule, …)
         → EDGE обновляет edge_campaigns (config_json.money, флаги лидерборда)

Пользователь → Клиент → GET /api/edge/money/campaign-config?edgeId=
            → GET /api/edge/participant/leaderboard?edgeId=&kind=secondary
            → Рендер карточки ленты и полного свайп-экрана
```

Начисление по `money.scoringRules` идёт через события платформы → EDGE (`POST /v1/money/platform-events`, хуки чата/звонков, постов и реакций). **Посты:** не черновик (в т.ч. выход из черновика) → счётчик `edge_money_post_counters` → milestone `post_created_milestone` (ключ `money_post_created`). **Реакции на посты:** первая реакция другого пользователя на пост автора → `edge_money_profile_like_counters` → `profile_likes_received_milestone` (`money_profile_likes`); смена эмодзи не дублирует; свой пост не считается. **Подписка на создателя:** при первом follow на профиль владельца MONEY-кампании тот же вызов `POST /v1/participant/follow-reward` дополнительно обходит опубликованные money-кампании и применяет правило `follow_creator` (grant `money_follow_creator`, опционально `maxPointsPerDay` UTC); companion-кампании с `follow_reward_enabled` для `edge_type = money` в этот путь не попадают — без двойного начисления за один follow.

## 5. Сознательное разделение «админ vs пользователь»

| Действие | Создатель | Пользователь |
|----------|-----------|--------------|
| Задать правила и призы | ✅ | ❌ |
| Видеть всех в рейтинге (в рамках лимита API) | Только если смотрит как игрок с тем же API; отдельной «админ-таблицы» в этом модуле нет | ✅ топ + себя в полной версии; в ленте — укороченный топ |
| Менять дату окончания / видимость поста | ✅ (борд + меню поста для audience) | ❌ |
| Свайпать экраны игры | Может как обычный пользователь в превью | ✅ |
| Получать баллы за чат/инвайты/посты/реакции и т.д. | Не цель роли; начисление — по бизнес-правилам | ✅ по включённым правилам и хукам платформы → EDGE |
