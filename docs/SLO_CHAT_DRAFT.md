# SLO (черновик): открытие чата и список сообщений

Цели для итераций; цифры уточнять по nginx access log, APM или RUM.

| Метрика | Цель p95 (черновик) | Откуда брать |
|--------|---------------------|--------------|
| `GET /api/chats/:id/messages` (первый экран, limit по `MESSAGES_PAGE`) | ≤ 800 ms на стабильном проде | nginx `$request_time`, поле `list_messages_ms` в логах приложения (длинные запросы) |
| От тапа по строке чата до отрисовки первого кадра треда (включая кэш) | Субъективно «без заметной паузы» на Wi‑Fi; на 3G — явный skeleton/кэш | Chrome Performance / ручной таймер |
| Восстановление после offline → online | ≤ 5 s до консистентного хвоста или явной ошибки | Ручной сценарий + WS логи |

Пересмотр: зафиксировать дату в [`PERFORMANCE_CONFIDENCE_FORWARD_ROADMAP.md`](./PERFORMANCE_CONFIDENCE_FORWARD_ROADMAP.md) после появления стабильных замеров.
