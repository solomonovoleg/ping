# Чеклист качества: каждый экран и каждая деталь

Использовать при добавлении или изменении экранов и фич. Цель — стабильное приложение с продуманным интерфейсом.

---

## На каждый экран/список

| Проверка | Да |
|----------|-----|
| Есть состояние **загрузки** (скелетон или спиннер в том же формате, что контент) | |
| Есть состояние **ошибки** (текст + кнопка «Повторить» или тост) | |
| Есть **пустое состояние** (ListEmptyState: иконка, заголовок, описание, при необходимости одна кнопка) | |
| Нет «висящего» старого контента при смене контекста (например другой чат) или при ошибке | |

---

## На каждое действие пользователя

| Проверка | Да |
|----------|-----|
| Есть **мгновенный визуальный отклик** (tap scale, изменение состояния кнопки) до ответа сервера | |
| Критичные действия (отправка, сохранение): при ошибке показывается **тост или сообщение**, не тишина | |
| Кнопка не даёт многократного нажатия во время запроса (disabled или loading) | |
| Где уместно (отправка, лайк, таб в навбаре): **хаптик** на тап | |

---

## Единый стиль

| Проверка | Да |
|----------|-----|
| Пустые списки через **ListEmptyState**, не кастомные блоки с другим стилем | |
| Скелетоны через **Skeleton** из ui/skeleton, один стиль (pulse) | |
| Длительности анимаций из **lib/motion** (DURATION_FAST_MS, DURATION_NORMAL_MS) | |
| Учтён **prefers-reduced-motion**: при true — только fade или без анимации | |
| Интерактивные элементы не меньше **--uix-touch-min** по области нажатия | |
| Иконки без подписи имеют **aria-label** | |

---

## Стабильность кода

| Проверка | Да |
|----------|-----|
| Запросы к API: ошибки **обработаны** (тост, сообщение, retry), не пустой catch в критичных путях | |
| При смене маршрута/контекста **очищается** состояние (например чат/messages при смене chatId) | |
| Нет утечек: таймеры и подписки **снимаются** в cleanup useEffect | |

---

## Быстрый проход по экранам (референс)

- **Чаты**: скелетоны ✓, ошибка + Повторить ✓, ListEmptyState ✓, ChatRow memo ✓.
- **ChatDetail**: загрузка/ошибка/пусто, read+refresh retry+toast ✓, типинг/voice indicators ✓.
- **Лента (Posts)**: скелетоны, ошибка, пусто — проверить единообразие с Chats.
- **Профиль**: загрузка/ошибка/пусто, копирование ссылки с тостом при ошибке ✓.
- **Настройки**: реферальная ссылка — тост при ошибке копирования ✓.
- **Login/Onboarding**: ошибки от сервера показываются, сессия/токен обработаны ✓.
- **Модалки (комменты, создание поста)**: AnimatePresence + exit, хаптик на отправку ✓.
