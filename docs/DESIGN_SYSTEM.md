# Design System — архитектура и стандарты качества

Единая дизайн-система PING: от токенов до экранов. Цель — мировой уровень: предсказуемость, доступность, консистентность (по образцу Telegram / Apple HIG).

---

## 1. Слои архитектуры (снизу вверх)

```
┌─────────────────────────────────────────────────────────┐
│  Screens (Pages)                                        │  ← Экраны используют только примитивы и паттерны
├─────────────────────────────────────────────────────────┤
│  Patterns (Empty, Error, Loading, List row, Nav)        │  ← Повторяемые блоки из компонентов
├─────────────────────────────────────────────────────────┤
│  Components (Button, Input, Card, PageShell, Typography) │  ← UI-компоненты на токенах
├─────────────────────────────────────────────────────────┤
│  Tokens (spacing, typography, radius, motion, color)    │  ← Переменные в index.css
└─────────────────────────────────────────────────────────┘
```

**Правило:** экран не задаёт произвольные отступы/шрифты/радиусы — только токены и компоненты.

---

## 2. Токены (источник правды: `client/src/index.css`)

### 2.1 Spacing (сетка 4px)
| Токен | Значение | Использование |
|-------|----------|---------------|
| `--uix-space-1` | 4px | Иконка–текст, минимальный зазор |
| `--uix-space-2` | 8px | Внутри кнопок, чекбоксов |
| `--uix-space-3` | 12px | Поля формы, внутренние отступы карточки |
| `--uix-space-4` | 16px | **Отступ контента от края**, между секциями |
| `--uix-space-5` | 24px | Между крупными блоками |
| `--uix-space-6` | 32px | Крупные паузы |
| `--uix-space-7` | 48px | Секции |
| `--uix-space-8` | 64px | Редко |

### 2.2 Typography (роли, не «просто размер»)
| Токен | Назначение |
|-------|------------|
| `--uix-text-title` | Заголовок экрана (Чаты, Лента, Настройки) |
| `--uix-text-list-primary` | Имя в списке (чат, пользователь, пост) |
| `--uix-text-list-secondary` | Превью, подпись, вторичная строка |
| `--uix-text-caption` | Время, мета, подсказки |
| `--uix-text-input` | Поля ввода (17px, iOS-стиль) |

### 2.3 Radius (одна шкала)
Используем `--radius` и производные: `--radius-sm` … `--radius-2xl`.  
Кнопки: `rounded-lg`. Карточки/модалки: `rounded-xl` или `rounded-2xl`. Инпуты: `rounded-lg`.  
Не использовать жёсткие `rounded-[12px]`.

### 2.4 Motion
| Токен | Значение | Использование |
|-------|----------|---------------|
| `--uix-duration-fast` | 75ms | Hover, active, toggle |
| `--uix-duration-normal` | 200ms | Открытие модалки, появление |
| `--uix-easing-out` | ease-out | Выезд, масштаб |

### 2.5 Touch & a11y
- `--uix-touch-min: 44px` — минимальная область нажатия для всех интерактивных элементов.
- Контраст текста и фона — не ниже WCAG AA.

## 3. Компоненты (обязательные контракты)

### 3.1 Button
- Размеры: `default` (компактный), `lg` (min-height = `--uix-touch-min`, для главных действий), `icon`.
- Радиус: только из темы (`rounded-lg` для lg).
- Не переопределять высоту/паддинги на экранах — только variant + size.

### 3.2 Input
- Размеры: `default` (списки, поиск), `lg` (формы входа/онбординг: `--uix-touch-min`, `--uix-text-input`).
- Радиус: `rounded-lg`.

### 3.3 PageShell (контейнер экрана)
- Горизонтальный отступ: `--uix-space-4` (класс `.uix-content-x` или компонент).
- Заголовок экрана: `text-[length:var(--uix-text-title)] font-bold`.

### 3.4 Списки (чаты, посты, настройки)
- Высота строки: не меньше `--uix-touch-min`.
- Основная строка: `--uix-text-list-primary`, вторичная: `--uix-text-list-secondary`, время/мета: `--uix-text-caption`.

### 3.5 Состояния
- **Empty:** компонент `ListEmptyState` (иконка, заголовок, описание, опционально CTA).
- **Error:** компонент `FormError` (форма) или блок с `text-destructive` и иконкой.
- **Loading:** скелетоны списка (Skeleton), не только «Загрузка…».

## 4. Паттерны экранов

| Эран | Отступ контента | Заголовок | Кнопки |
|------|------------------|-----------|--------|
| Чаты | `uix-content-x` | `uix-text-title` | size default/lg по контексту |
| Лента | `uix-content-x` | как Чаты | CTA «Написать» — lg |
| Настройки | `uix-content-x` | `uix-text-title` | Строки min-h touch-min |
| Логин / Онбординг | центрированный блок | — | Главная кнопка — lg |
| Профиль | `uix-content-x` | как Чаты | — |

## 5. Чек-лист качества (перед мержем)

- [ ] Нет произвольных отступов: только `var(--uix-space-*)` или классы на них.
- [ ] Нет произвольных размеров шрифта: только `var(--uix-text-*)` или компоненты.
- [ ] Нет жёстких радиусов: только `rounded-lg`, `rounded-xl` и т.д. из темы.
- [ ] Интерактивные элементы не ниже 44px по высоте/области нажатия.
- [ ] Пустые состояния — через `ListEmptyState` или Empty.
- [ ] Ошибки форм — через `FormError`.
- [ ] Критичные действия (Выйти, Удалить) — с подписью или стабильным tooltip.

## 6. Файлы-источники

| Что | Где |
|-----|-----|
| Токены и утилиты | `client/src/index.css` |
| Текстовые утилиты | классы `.uix-text-title`, `.uix-text-list-primary` и т.д. |
| Компоненты | `client/src/components/ui/` |
| Паттерны (Empty, FormError) | `empty.tsx`, `form-error.tsx` |
| Документация токенов | `docs/UIX_TOKENS.md` |
| Задачи по внедрению | `docs/UIX_TODO.md` |

Новые фичи и правки UI проходят через эту систему; исключения не допускаются без явного решения в коде и комментария.
