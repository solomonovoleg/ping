# Шаблон блока Metrics (конец каждой части 001–127)

Скопируйте в конец секции части и заполните:

```markdown
### Metrics — Часть NNN

| Метрика | Значение |
|---------|----------|
| **Coverage** | _% (0–100)_ |
| **HealthScore** | _1–5_ |
| **Risk** | P0: _n_, P1: _n_, P2: _n_ |
| **Reliability** | _Red / Amber / Green_ — _одна строка_ |
| **UXFriction** | _1–5_ |
| **ParityVsGiants** | _1–5_ (эталон: _Telegram / WhatsApp / Instagram / …_) |
| **Evidence** | `path1`, `path2`, … (3–8 ссылок на код или доки) |
```

**Правила интерпретации**

- **Coverage**: доля сценариев/файлов из плана части, реально просмотренных при аудите.
- **HealthScore**: субъективная целостность зоны (не путать с «нравится продукт»).
- **P0**: эксплуатационный риск (утечка данных, обход auth, потеря данных); **P1**: серьёзный UX/доступность/стабильность; **P2**: полировка и долг.
- **Reliability**: для сети/WS/медиа; для чистого UI можно писать Green с пометкой «N/A сеть».
