## Часть 059 — Состояния экранов

- **R01** — У каждого публичного списка явные loading / success / error / empty. **Готово:** чеклист по экрану + скрин. **Эффект:** меньше «пустого молчания».
- **R02** — Ошибка сети с кнопкой «Повторить» на критичных путях (чат, лента). **Готово:** UX-ревью 5 сценариев. **Эффект:** выше завершение задач.
- **R03** — Скелетон вместо спиннера на первой загрузке ленты/профиля. **Готово:** `PostsFeedSkeleton` и аналоги подключены. **Эффект:** воспринимаемая скорость.
- **R04** — Пустое состояние с одним главным CTA. **Готово:** использование `ListEmptyState`. **Эффект:** рост конверсии в действие.
- **R05** — Не показывать устаревшие данные при смене контекста (chatId). **Готово:** тест-кейс в QA. **Эффект:** доверие к мессенджеру.

## Часть 060 — Дизайн-система

- **R06** — Все новые кнопки из `components/ui/button` (или согласованный вариант). **Готово:** code review правило. **Эффект:** визуальная целостность.

## Часть 061 — Ошибки и обратная связь

- **R11** — Тост при провале критичной мутации (отправка, сохранение, удаление). **Готово:** сценарии в QA. **Эффект:** пользователь понимает исход.
- **R12** — Не глотать ошибки в `catch` без лога в dev на критичных путях. **Готово:** eslint/ручной аудит. **Эффект:** быстрее отладка.
- **R13** — Оптимистичный UI с откатом при 4xx/5xx для сообщений где безопасно. **Готово:** покрытие `useSendMessage`. **Эффект:** ощущение скорости.
- **R14** — Понятный текст при 401/403 (сессия истекла). **Готово:** единый компонент/тост. **Эффект:** меньше обращений в поддержку.
- **R15** — Логирование серверных 5xx с `requestId`. **Готово:** middleware. **Эффект:** расследование инцидентов.

## Часть 062 — Перформанс списков

- **R16** — Виртуализация длинного треда по гайду `CHAT_THREAD_VIRTUALIZATION.md`. **Готово:** метрики FPS на 2k сообщений. **Эффект:** плавный скролл.

- **R18** — Prefetch следующей страницы ленты при приближении к концу. **Готово:** TanStack Query настройки. **Эффект:** непрерывность ленты.

## Часть 063 — Навигация

- **R21** — Единый паттерн «Назад» для вложенных постов и EDGE fullscreen. **Готово:** `edge-companion-navigation` без поломок. **Эффект:** меньше потерянных пользователей.
- **R22** — Сохранение позиции ленты при возврате где возможно. **Готово:** UX-приёмка. **Эффект:** комфорт как в Instagram.
- **R23** — Не открывать дубли одного чата в нескольких вкладках без предупреждения (опционально). **Готово:** продуктовое решение зафиксировано. **Эффект:** меньше рассинхрона WS.

- **R25** — Onboarding не блокирует deep link после логина. **Готово:** тест `auth-return-path`. **Эффект:** меньше брошенных сценариев.

## Часть 067 — Доступность

- **R41** — Контраст текста на градиентах PULSE-профиля WCAG AA где возможно. **Готово:** автоматическая проверка ключевых экранов. **Эффект:** читаемость.
