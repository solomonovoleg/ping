# Юзабилити: мобильная версия и сильнее Telegram

Рекомендации по UX/UI для **мобильного приложения** (Capacitor, PWA на телефоне): жесты, тапы, обратная связь — без упора на клавиатуру (Esc и т.п. остаются только для веба/десктопа).

---

## Фокус: мобильная версия

- **Тап и жесты** — основной способ управления: свайп «назад», свайпы по строкам, долгое нажатие, pull-to-refresh.
- **Закрытие модалок на мобильном** — тап по затемнённому фону (оверлей) и явная кнопка «Закрыть». Клавиша Esc на телефоне не используется.
- **Клавиатура** — только когда открыта виртуальная клавиатура (поле ввода): Enter = отправить, остальное — по желанию для веба.

---

## 1. Где Telegram проигрывает на мобильном (и где мы можем выиграть)

| Область | Telegram сейчас | Наш потенциал |
|--------|-----------------|--------------|
| **Жесты** | Почти нет свайпов по спискам, только базовый pull-to-refresh | Свайп по чату — закрепить/удалить; свайп по посту — лайк/сохранить; свайп от левого края — «назад» |
| **Обратная связь** | Мало анимаций, скелетоны не везде | tap-scale, хаптик, скелетоны, оптимистичный UI — уже заложено; усилить единообразие |
| **Модалки и панели** | Закрытие кнопкой или свайпом вниз | Тап по оверлею всегда закрывает; нижние панели — свайп вниз или кнопка; одна логика везде |
| **Лента и чаты** | Чаты — сила; лента отдельно | Один продукт: чаты + лента + борд, быстрый переключатель внизу |
| **Доступность** | Средняя | Крупные зоны нажатия (--uix-touch-min), aria-label, reduced motion — довести везде |

### Быстрые победы — мобильная версия (1–2 недели)

1. **Закрытие модалок и панелей на мобильном**
   - **Тап по оверлею** (затемнённый фон) всегда закрывает модалку — проверить все модалки (комменты, эмодзи, вложения и т.д.).
   - Нижние панели (например, комментарии): кроме кнопки «Закрыть» — **свайп вниз** по панели закрывает (уже может быть через `drag="y"` и `onDragEnd` или по порогу).
   - **Эффект:** привычное поведение: «тап мимо = закрыть», без поиска крестика.

2. **Жест «назад»**
   - Свайп от **левого края** экрана — переход назад (чат → список чатов, профиль → лента и т.д.).
   - Реализация: зона ~20–30 px у левого края, `touchstart`/`touchmove`/`touchend` — при достаточном свайпе вправо вызывать `history.back()` или `setLocation` на предыдущий маршрут. Можно показывать лёгкую «полоску» след за пальцем.
   - Кнопка «Назад» в шапке остаётся; жест дублирует её для удобства одной рукой.
   - **Эффект:** как в нативных iOS/Android — не обязательно тянуться к кнопке.

3. **Единый pull-to-refresh**
   - Один и тот же жест «потянуть вниз = обновить» на всех экранах со списком: чаты, лента, контакты, сохранённые.
   - Одна и та же анимация (из `lib/motion`), один порог срабатывания.
   - **Эффект:** предсказуемость: «потянул — обновилось».

4. **Крупные и предсказуемые зоны нажатия**
   - Все интерактивные элементы не меньше `--uix-touch-min` (уже в чеклисте). Проверить: иконки в шапке чата, кнопки в панели ввода, пункты контекстного меню.
   - **Эффект:** меньше промахов и двойных тапов.

5. **Хаптик на ключевых действиях**
   - Уже есть на отправке, лайках, навбаре. Добавить/проверить: отправка комментария, «Опубликовать», переключение табов, долгое нажатие (контекстное меню).
   - **Эффект:** тактильное подтверждение без перегруза.

*(Для веба/десктопа отдельно: Esc закрывает модалки, Cmd+K — поиск; это не для мобильной версии.)*

### Средний срок (2–4 недели)

6. **Свайпы по строкам списка**
   - **Чаты:** свайп влево по строке чата — «Закрепить» / «Удалить» / «Прочитать» (как в Mail).
   - **Лента:** свайп вправо по посту — быстрый лайк; свайп влево — «Сохранить» или «Скрыть».
   - Реализация: обёртка с `motion.div` + `drag="x"` и `onDragEnd` или готовый компонент (например, `react-swipeable`), порог срабатывания и анимация из `lib/motion`.
   - **Эффект:** «нативное» ощущение и быстрые действия без долгого тапа.

7. **Переходы между экранами**
   - При переходе «список → деталь» (чат, профиль, пост): не просто смена контента, а лёгкая анимация «вперёд» (slide-in справа или scale+fade).
   - При «назад» — обратная анимация (или симметричный slide-out).
   - Уже есть `contentKey` и `animate-in` в AppLayout — унифицировать длительность и easing из `lib/motion` для всех страниц.
   - **Эффект:** ощущение «глубины» и ориентации, как в iOS/современных веб-приложениях.

8. **Индикатор «онлайн» и качества соединения**
   - Небольшая точка/иконка в шапке или рядом с аватаром: зелёный — онлайн, жёлтый — нестабильно, серый — офлайн.
   - Подписка на WebSocket `open`/`close`/`reconnect` и, при желании, на `navigator.onLine`.
   - **Эффект:** пользователь видит, «живой» ли чат и нужно ли повторить действие.

9. **Умное пустое состояние и первый запуск**
   - «Нет чатов» — не просто иконка, а один CTA: «Найти контакт» или «Начать с ленты».
   - При первом входе — короткий онбординг (1–2 экрана): «Чаты здесь», «Лента здесь», «Профиль — по логотипу».
   - **Эффект:** меньше «пустого экрана», быстрее понимание продукта.

10. **Тёмная тема и системная тема**
    - Если ещё нет: тема по `prefers-color-scheme` и переключатель в настройках (light/dark/system).
    - **Эффект:** комфорт вечером и соответствие ожиданиям «современного веба».

### Долгий горизонт (1–2 месяца)

11. **Единый поиск (чаты + люди + посты)**
    - Один ввод: поиск по чатам, пользователям и по тексту постов (если бэкенд поддерживает).
    - Результаты с табами или секциями: «Чаты», «Люди», «Посты» — переход по клику/клавише.
    - **Эффект:** один поиск вместо трёх разных экранов, как в лучших продуктах Web 4.0.

12. **Быстрые действия (Quick actions)**
    - Долгое нажатие на чат: «Закрепить», «Удалить», «Пометить прочитанным».
    - Долгое нажатие на сообщение: «Копировать», «Переслать», «Ответить», «Редактировать».
    - Уже есть контекстные меню — вынести в контекстное меню по long press на мобильном и правый клик на десктопе.
    - **Эффект:** мощность Telegram, но без перегруза интерфейса.

13. **Офлайн и синхронизация**
    - Кэш последних чатов/ленты (например, через TanStack Query persist или localStorage) и индикатор «офлайн» (OfflineBanner уже есть).
    - При возврате онлайн — тихий refetch и тост «Обновлено», если были изменения.
    - **Эффект:** приложение не «пустое» в метро и при плохом интернете.

14. **Микро-персонализация**
    - Порядок табов в навбаре (чаты / лента / борд) или скрытие редко используемого.
    - Размер шрифта в настройках (компактный / обычный / крупный).
    - **Эффект:** «под меня», без усложнения первого запуска.

## 3. Принципы для мобильной версии

- **Управление жестами и тапом** — свайп «назад», свайпы по строкам, долгое нажатие, pull-to-refresh; закрытие модалок — тап по оверлею или свайп вниз для нижних панелей.
- **Мгновенная обратная связь** — оптимистичный UI, скелетоны, анимации из lib/motion, хаптик на действиях (без хаптика на скролле).
- **Прозрачность состояния** — онлайн/офлайн, загрузка, ошибка с «Повторить», пустые состояния с одним CTA.
- **Доступность** — зоны нажатия не меньше --uix-touch-min, aria-label у иконок, учёт reduced motion.

Клавиатурные shortcuts (Esc, Cmd+K и т.д.) — только для веба/десктопа; в мобильной версии не приоритет.
