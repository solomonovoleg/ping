# PING MOOT — функционал для пользователей (материал для блога)

Документ для маркетинга и статей: **название функции**, **описание для пользователя**, **чем отличается от типичных мессенджеров**. Сводка по продукту (мессенджер + лента + звонки + голосовой слой EDGE и др.); технические детали деплоя и флагов здесь не раскрываются.

---

## 1. Один продукт: общение и лента рядом

| | |
|--|--|
| **Описание** | Чаты, личные сообщения, посты в ленте, сториз, профили и подписки живут в одном приложении — не нужно переключаться между «чистым мессенджером» и отдельной соцсетью. |
| **Отличие** | Во многих мессенджерах контент автора размазан по каналам или статусам; в PING MOOT **лента и диалог** связаны с профилем и подписками в одной экосистеме. |

---

## 2. Чаты в духе PULSE (премиальный интерфейс)

| | |
|--|--|
| **Описание** | Экран чата собран под макет PULSE: тёмная и светлая тема, продуманные списки, модалки, жесты и анимации с учётом доступности. |
| **Отличие** | Упор не на «функциональную таблицу», а на **цельный визуальный язык** как у соцприложений верхнего сегмента — редкость для кастомных и self-hosted мессенджеров. |

---

## 3. Голосовой слой «Пингок Микро»

| | |
|--|--|
| **Описание** | Долгое нажатие на центральный логотип в нижнем меню открывает голосовой оверлей: распознавание речи, разбор команды, поиск по памяти и сценарии — напоминания, задачи, сообщение контакту, **старт звонка**, выдача релевантных постов из ленты. |
| **Отличие** | Это не отдельный голосовой ассистент «в вакууме», а **слой поверх мессенджера и ленты**: голос как быстрый способ сделать то, что уже есть в продукте. |

---

## 4. Личные и групповые звонки (голос и видео)

| | |
|--|--|
| **Описание** | Звонки один на один на WebRTC; групповые комнаты в чатах (mesh, до 12 участников), баннер активного созвона, подключение из чата. |
| **Отличие** | Групповой звонок **привязан к чату** как к контексту; плюс демонстрация экрана в групповом видеозвонке, **титры (субтитры)** с возможностью серверного распознавания речи (в том числе self-hosted на своём сервере). У типичного мессенджера такого набора в одном месте часто нет. |

---

## 5. Сториз и просмотр историй

| | |
|--|--|
| **Описание** | Кольцо сториз в профиле, полноэкранный просмотр, медиа из «ленты жизни» автора. |
| **Отличие** | Сториз **встроены в профиль и социальный слой**, а не выглядят как отдельный модуль «ради галочки». |

---

## 6. Посты, реакции, комментарии

| | |
|--|--|
| **Описание** | Лента постов, реакции, треды комментариев, медиа (включая работу с видео, обрезку там, где это предусмотрено в клиенте). |
| **Отличие** | Полноценная **лента с вовлечением** (реакции и комментарии) внутри того же приложения, что и чаты — ближе к «соцсеть + мессенджер», чем к сценарию «только переписка». |

---

## 7. Профиль PULSE: обложка, табы, закреплённое

| | |
|--|--|
| **Описание** | Профиль с параллаксом, кольцом сториз, вкладками и сеткой постов; можно закреплять посты и сториз, собирать **закреплённые подборки** (пины). |
| **Отличие** | Профиль оформлен как **витрина автора**, а не как сухая карточка «ник и аватар». |

---

## 8. EDGE Companion — интерактив у автора в ленте

| | |
|--|--|
| **Описание** | У поста может быть связка с EDGE: отдельный интерактивный сценарий (в развитии — персонаж-тамагочи, задания, уход, состояния, баллы, лидерборд, призы). Игровая логика вынесена в отдельный сервис; лента и чаты остаются стабильными, если интерактив временно недоступен. |
| **Отличие** | Редко у кого в ленте есть **игровой или кампейнный слой с отдельным состоянием на пользователя**; это ближе к удержанию и вовлечению через контент, чем к обычному посту с картинкой. |

---

## 9. AI Search / «память» диалогов

| | |
|--|--|
| **Описание** | После активности в чатах система может **порциями** извлекать темы и сигналы из переписки и строить индекс для поиска и сценариев (в том числе голосового слоя), без необходимости каждый раз обрабатывать весь архив сообщений. |
| **Отличие** | Не только поиск по точному совпадению текста, а **смысловой слой поверх истории чатов** — в связке с Пингоком даёт ощущение, что приложение помнит контекст; для небольших и кастомных мессенджеров это нетипично. |

---

## 10. «Вайб» чата

| | |
|--|--|
| **Описание** | Темы оформления беседы (vibe), чтобы чаты визуально отличались друг от друга. |
| **Отличие** | Персонализация **на уровне комнаты**, а не только глобальная тёмная тема всего приложения. |

---

## 11. Сохранённые сообщения

| | |
|--|--|
| **Описание** | Избранное внутри мессенджера: важные сообщения можно отложить в сохранённые. |
| **Отличие** | Ожидаемая функция зрелого мессенджера; здесь она **встроена в ту же экосистему**, что лента и профиль. |

---

## 12. Перевод и орфография

| | |
|--|--|
| **Описание** | Перевод сообщений и проверка орфографии как вспомогательные функции переписки. |
| **Отличие** | Продукт удобнее для **рабочего и мультиязычного** общения без смены приложения. |

---

## 13. AI-чат

| | |
|--|--|
| **Описание** | Отдельный сценарий диалога с AI внутри платформы. |
| **Отличие** | AI не только как «поиск», но и как **явный собеседник** в рамках одного аккаунта и приложения. |

---

## 14. Глобальный поиск людей

| | |
|--|--|
| **Описание** | Поиск по имени, нику, ID, номеру телефона с быстрыми действиями (подписка, старт личного чата и т.д.). |
| **Отличие** | Рост сети и онбординг **из одной строки поиска**, без обхода через сценарии «только контакты из телефонной книги». |

---

## 15. Блокировки с пресетами

| | |
|--|--|
| **Описание** | Блокировка пользователя из чата, профиля, контекста комментариев; где предусмотрено — **готовые пресеты формулировок** для причины или жалобы. |
| **Отличие** | Меньше трения при личных границах и репортах: **структурированно**, а не «придумайте текст с нуля». |

---

## 16. Сервисные сообщения и хост-чат

| | |
|--|--|
| **Описание** | Системные и сервисные цепочки сообщений от платформы: шаблоны, рассылки, обратная связь. |
| **Отличие** | Основа для **официальных уведомлений и поддержки** в том же чатовом интерфейсе, что и общение с людьми. |

---

## 17. Доска: треки и история звонков

| | |
|--|--|
| **Описание** | Сценарий «треков» и связка с историей звонков на доске — для проектной и рабочей коммуникации внутри продукта. |
| **Отличие** | Сдвиг в сторону **рабочей доски поверх чатов** — ближе к командным продуктам, чем к «чистому» мессенджеру. |

---

## 18. Нативные приложения (iOS / Android)

| | |
|--|--|
| **Описание** | Веб-клиент оборачивается в нативные оболочки (Capacitor): пуши, камера, тактильный отклик, привычный мобильный UX. |
| **Отличие** | Не только сайт в браузере, а путь к **установке из стора** с нативными возможностями. |

---

## 19. Данные и память на устройстве

| | |
|--|--|
| **Описание** | В настройках — управление кэшем медиа, сохранёнными сообщениями, выгрузка данных пользователя (например в JSON). |
| **Отличие** | Акцент на **прозрачности и контроле**: что хранится локально и как получить свою копию данных. |

---

## 20. Реферальная механика

| | |
|--|--|
| **Описание** | Встроенная реферальная логика для приглашения новых пользователей. |
| **Отличие** | Рост сети **изнутри приложения**, без отдельной внешней воронки. |

---

## Идеи для серии постов в блоге

1. **«Не только чаты»** — лента, профиль, сториз, посты и реакции.  
2. **«Голос и звонки»** — Пингок Микро, личные и групповые звонки, титры и демонстрация экрана.  
3. **«Авторы и удержание»** — EDGE, пины в профиле, сервисный слой.  
4. **«Ум и память»** — AI-чат и смысловой индекс переписок (простым языком, без перегруза техническими терминами).
