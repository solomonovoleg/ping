# Блок 1 — UGC и модерация (сторы)

Клиентский модуль для **жалоб на контент** (`POST /api/reports`): чат, пост, профиль, сториз, **комментарий** (`targetType: comment`). Для комментария и сообщения клиент может передать **`contextPostId`** / **`contextChatId`** (сохраняются в БД и дают диплинк в админке).

- Типы целей синхронизированы с `shared/schema/content-reports.ts`.
- Каждый файл в папке — не длиннее ~200 строк.
- Следующие блоки стор-модерации — отдельные папки рядом (`block-02-…` и т.д.).
