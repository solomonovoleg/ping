# Блок 5 — App Store: листинг и метаданные (Connect)

Раздел **`/admin/store-review-metadata`**: чеклист по **точности метаданных**, **скриншотам**, **возрастному рейтингу** и сопутствующим полям в App Store Connect, включая актуальные минимальные требования к SDK/Xcode на дату сабмита.

- Опирается на справку Apple (ссылки на странице) и **App Review Guidelines** (в т.ч. точность описания продукта).
- Не дублирует UGC (блок 3) и Privacy (блок 4).
