# Блок 4 — App Store Connect: Privacy, удаление аккаунта, шифрование

Отдельный раздел **`/admin/store-review-privacy`**: чеклист по требованиям Apple, которые задаются **вне кода** (Connect) или проверяются при ревью: удаление аккаунта, **App Privacy Details**, **export compliance**, Support URL, описания использования камеры/микрофона в iOS, privacy manifests / required reasons для SDK.

- Опирается на публичные материалы Apple (ссылки на странице).
- Не дублирует §1.2 UGC — см. блок 3 (`/admin/store-review`).
