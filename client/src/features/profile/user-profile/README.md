# User profile (экран)

Оболочка PULSE остаётся в `../pulse-profile/`; здесь — **данные, сториз/посты, модалки** для `UserProfile`.

| Путь | Роль |
|------|------|
| `useUserProfilePage.ts` | Хук: роут, запросы, обработчики (≤500 строк). |
| `hooks/` | Узкие хуки (напр. мутации лайков/удаления поста). |
| `i18n.ru.ts` | Все пользовательские строки модуля (RU); логика не смешивается с текстом. |
| `model/` | Чистые функции: разбор `fetchProfilePage`, derived-поля для layout. |
| `components/` | Изолированные куски UI (лента постов, sheet’ы, загрузка/404 чужого профиля). |
| `utils/` | Чипы даты/пола, мета поста для PULSE. |
| `constants.ts` | Реакции и прочие константы экрана. |

**Точка входа в приложение:** `pages/UserProfile.tsx` — только связывает хук с `PulseProfileLayout` и порталами.

**Импорт из фичи:** `@/features/profile/user-profile` (см. `index.ts`).

**Карта проекта (включая клиент):** `docs/PROJECT_MAP.md`.

Расширять: новый компонент в `components/`, новые строки в `i18n.ru.ts`, парсинг/derived в `model/`.
