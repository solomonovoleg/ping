# PULSE profile (экспорт `pulse-profile-export`)

Вёрстка по `pulse-profile-export` / **MobileProfile**: параллакс-обложка, pill `@username` + chevron, **градиентное кольцо** у аватара (как в макете), чипы, **«3 общих подписчика»**, хайлайты. Декоративный статус-бар макета (время, сигнал, батарея) в вебе не показываем — только `safe-area` для кнопок. Нижняя полоса **Чаты · Лента · PULSE · Борд · Профиль** — общая из `AppLayout` (в экране чата скрыта). Сториз по-прежнему через `StoryViewer`.

- **`PulseProfileLayout`** — оболочка; данные и посты передаются с `UserProfile.tsx`. Светлая/тёмная оболочка следует **глобальной теме** (`html.dark` из **Настроек**), отдельного переключателя на профиле нет.
- **`MobileStoriesViewer`** из архива не подключался: в продукте остаётся **`StoryViewer`** и текущие API сториз.

Исходный архив: внешняя папка `pulse-profile-export` (документация в `README.md`).
