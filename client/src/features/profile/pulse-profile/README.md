# PULSE profile (экспорт `pulse-profile-export`)

Вёрстка по `pulse-profile-export` / **MobileProfile**: параллакс-обложка, pill `@username` + chevron, **градиентное кольцо** у аватара (как в макете). Блок **аватар + Посты / Подписчики / Подписки** — в одной **поднятой карточке** на стыке обложки и тела профиля (как в референсе). Ниже — имя, чипы, строка **общих подписчиков** (реальные данные с API: из ваших подписок, кто подписан на открытый профиль), хайлайты. Декоративный статус-бар макета (время, сигнал, батарея) в вебе не показываем — только `safe-area` для кнопок. Нижняя полоса **Чаты · Лента · PULSE · Борд · Профиль** — общая из `AppLayout` (в экране чата скрыта). Сториз по-прежнему через `StoryViewer`.

- **`PulseProfileLayout`** — оболочка; данные и посты передаются с `UserProfile.tsx`. Светлая/тёмная оболочка следует **глобальной теме** (`html.dark` из **Настроек**), отдельного переключателя на профиле нет. Разметка и мелкие куски вынесены в `layout/` (секции обложки, карточка героя, блок имени, закреп, вкладки); публичный API по-прежнему из `PulseProfileLayout.tsx` / `index.ts`.
- Логика и модалки самого экрана профиля (сториз, посты, sheet’ы): **`../user-profile/`** (`useUserProfilePage`, см. `README.md` там).
- **`MobileStoriesViewer`** из архива не подключался: в продукте остаётся **`StoryViewer`** и текущие API сториз.

Исходный архив: внешняя папка `pulse-profile-export` (документация в `README.md`).
