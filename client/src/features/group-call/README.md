# Модуль групповых звонков (плагин)

**Статус:** каркас. По умолчанию **выключен** (`VITE_GROUP_CALLS_ENABLED` не задан или `0`).

## Изоляция

- Не импортируется из `CallContext`, `CallController`, `server/calls/ws.ts`, пока не будет явной фазы интеграции.
- Тет-а-тет звонки не трогаем: отдельные типы, стор, будущий сигналинг (отдельный namespace WS или отдельный путь).
- Деплой с этим модулем **безопасен**: при выключенном флаге код путей группового звонка не выполняется.

## Включение

1. **Клиент:** `VITE_GROUP_CALLS_ENABLED=1` при сборке.
2. **Сервер:** `GROUP_CALLS_ENABLED=1` в `.env` / `deploy.env`.
3. **Nginx:** отдельный `location = /group-calls` с WebSocket upgrade (см. `deploy/nginx-ping-moot.conf`).
4. Токен тот же, что для `/calls`: `POST /api/calls/token`, WS `wss://…/group-calls` + токен в `Sec-WebSocket-Protocol` (как `/calls`).

## Поведение

- Mesh WebRTC (полносвязная схема), до 12 участников на комнату; отдельный сигналинг от 1:1.
- UI: **PULSE AI template** (`ui/pulse-ai/GroupCallAILayout.tsx`) — сетка 2×2 / спикер / демонстрация, панель AI 280px, субтитры; логотип **PING MOOT**. Гайд: `ui/pulse-ai/DESIGN_RULES.md`.
- В чате группы: меню «⋯» → групповой звонок / видео; баннер «Идёт созвон» с кнопкой «Подключиться» (опрос раз в ~14 с).

## Структура

| Путь | Назначение |
|------|------------|
| `flags.ts` | Включение модуля (env) |
| `types/` | Контракты комнаты и участника |
| `store/` | Клиентское состояние комнаты (без WebRTC пока) |
| `hooks/` | Публичный хук-фасад для UI |
| `ui/pulse-ai/` | Тема ThCtx + `GroupCallAILayout` (шаблон `pulse-ai-call-template`) |

Лимит: **≤200 строк на файл**; логику дробить по подпапкам.
