# Как поставить приложение PING на iPhone / симулятор iOS

Делай шаги по порядку. Если что-то ругается — скопируй текст ошибки и напиши мне.

---

## Шаг 1: Открыть терминал в папке проекта

- В Cursor внизу есть панель **Terminal** (Терминал). Нажми на неё.
- Или: меню **Terminal → New Terminal**.
- Убедись, что ты в папке проекта. Введи и нажми Enter:

```bash
cd "/Users/admin/Downloads/SOLOMONOV/PING MOOT"
```

Дальше все команды вводишь **из этой папки**.

---

## Шаг 2: Один раз указать системе путь к Xcode

Нужно только один раз (потом не повторять). В терминале введи:

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

Нажми Enter. Система спросит **пароль от твоего Mac** (тот, которым входишь в комп). Вводи пароль и снова Enter. Символы при вводе не показываются — это нормально.

Если напишет **invalid developer directory** или **No such file** — значит **Xcode не установлен**. Тогда:
1. Открой **App Store** на Mac.
2. В поиске введи **Xcode** и нажми **Загрузить** (бесплатно, ~12 ГБ, установка долгая).
3. После установки один раз открой Xcode из папки «Программы» — он может доустановить компоненты.
4. Потом снова выполни в терминале: `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`

---

## Шаг 3: Собрать приложение и подготовить iOS-проект

В том же терминале (папка проекта) введи и нажми Enter:

```bash
npm run build:ios
```

Подожди, пока закончится (минута–две). Должно закончиться без ошибок. Если будет ошибка — скопируй её и пришли.

---

## Шаг 4: Открыть проект в Xcode

В терминале введи:

```bash
open ios/App/App.xcworkspace
```

Откроется **Xcode** с проектом. Важно: открывать именно **App.xcworkspace** (не .xcodeproj).

---

## Шаг 5: Запустить на симуляторе или на телефоне

В Xcode сверху есть меню выбора устройства:

- **Симулятор:** выбери, например, **iPhone 16** или **iPhone 15**.
- **Свой iPhone:** подключи телефон кабелем, разблокируй, при первом подключении на телефоне нажми «Доверять». В Xcode в списке устройств выбери свой iPhone.

Потом нажми большую кнопку **▶ Run** (или **Product → Run**). Xcode соберёт приложение и установит его на симулятор или на телефон.

Первый раз на своём iPhone может попросить: **Настройки → Основные → VPN и управление устройством** — там нажать на твой Apple ID и «Доверять».

## Кратко: что вводить по порядку

```bash
cd "/Users/admin/Downloads/SOLOMONOV/PING MOOT"
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
npm run build:ios
open ios/App/App.xcworkspace
```

Дальше в Xcode выбери устройство и нажми **▶ Run**.

Если на каком-то шаге будет ошибка — пришли её текст, разберём.
